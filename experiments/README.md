# Writing experiments

No experiment has run yet. Start with the proposed comparisons in the [research review](../research/notes/2026-10-03-ai-fiction-baseline.md), using the [experiment template](../templates/experiment.md).

Give each run a directory such as `EXP-001-plan-and-state/` containing its brief, model/method record, original samples, evaluation, and conclusion. Keep samples outside `book/chapters/` unless deliberately adopted with provenance.

Hold the premise, approximate length, and generation conditions reasonably constant when comparing methods. Change one useful factor at a time. Record actual settings and known limitations; randomize sample labels when feasible for reader review.

Evaluate interest, specificity, voice, causal coherence, character knowledge, and emotional consequence. Record concrete passages and reader explanations, not just scores. Human reading is the primary check; model critiques can suggest problems but are not independent reader evidence.

A successful local comparison is a candidate lesson. Test it on another premise or passage, include a counterexample, and check that it does not harm existing writing modes before proposing a public rule.
